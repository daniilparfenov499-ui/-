Ошибка: `значение NULL в столбце "email" нарушает ограничение NOT NULL`. При регистрации мы записываем только логин, пароль и имя, а колонка `email` в вашей таблице всё ещё обязательная. В миграции с `login` строки `->nullable()->change()` для `email` и `name` либо не попали, либо не сработали. Исправим новой миграцией.

**1. Создайте миграцию**
В терминале (папка `my-app`):
```
php artisan make:migration make_email_nullable_in_users_table --table=users
```

**2. Впишите код**
Откройте новый файл в `database/migrations` (название заканчивается на `make_email_nullable_in_users_table.php`) и замените метод `up()` на:
```php
public function up(): void
{
    Schema::table('users', function (Blueprint $table) {
        $table->string('email')->nullable()->change();
        $table->string('name')->nullable()->change();
    });
}
```

Метод `down()` оставьте как есть. Сохраните файл (`Ctrl+S`, курсор в окне с кодом).

**3. Примените**
```
php artisan migrate
```
Должна появиться строка с названием миграции и `DONE`.

**4. Проверьте регистрацию**
Откройте `http://127.0.0.1:8000/register` и зарегистрируйтесь заново. Теперь вас должно вернуть на главную, а в шапке появится ваш логин.

**Важная деталь про базу**
В тексте ошибки видно `Database: an`. Это база из вашего `.env`, и именно в ней сейчас пишет сайт. Когда будете проверять таблицу `users` в pgAdmin, открывайте её в базе **an**, а не в `danillons` (на прошлых фото вы смотрели другую базу). Миграция применится к той базе, что указана в `.env`, так что это правильно.

Если `migrate` напишет `Nothing to migrate`, значит файл миграции не создался или пустой. Тогда пришлите фото содержимого файла, посмотрим. А если регистрация пройдёт, напишите, и перейдём к проверке формы журналиста (часть 6).

<?php

namespace App\Http\Controllers;

use App\Models\Article;
use App\Models\Category;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class JournalistController extends Controller
{
    public function index()
    {
        $categories = Category::orderBy('name')->get();

        $myArticles = Article::where('user_id', Auth::id())
            ->with('category')
            ->latest()
            ->get();

        return view('journalist', compact('categories', 'myArticles'));
    }

    public function store(Request $request)
    {
        $data = $this->validated($request);
        $data['user_id'] = Auth::id();

        Article::create($data);

        return redirect()->route('home')->with('status', 'Статья опубликована.');
    }

    public function edit(Article $article)
    {
        $this->authorizeOwner($article);

        $categories = Category::orderBy('name')->get();

        return view('journalist_edit', compact('article', 'categories'));
    }

    public function update(Request $request, Article $article)
    {
        $this->authorizeOwner($article);

        $article->update($this->validated($request));

        return redirect()->route('journalist')->with('status', 'Статья обновлена.');
    }

    public function destroy(Article $article)
    {
        $this->authorizeOwner($article);

        $article->delete();

        return redirect()->route('journalist')->with('status', 'Статья удалена.');
    }

    private function authorizeOwner(Article $article): void
    {
        abort_unless($article->user_id === Auth::id(), 403);
    }

    private function validated(Request $request): array
    {
        return $request->validate([
            'title' => ['required', 'string', 'max:255'],
            'category_id' => ['required', 'exists:categories,id'],
            'body' => ['required', 'string', 'min:10'],
        ], [
            'title.required' => 'Введите заголовок.',
            'title.max' => 'Заголовок не длиннее 255 символов.',
            'category_id.required' => 'Выберите категорию.',
            'category_id.exists' => 'Такой категории не существует.',
            'body.required' => 'Введите текст статьи.',
            'body.min' => 'Текст статьи слишком короткий (минимум 10 символов).',
        ]);
    }
}

**1. Контроллер**

Откройте `app/Http/Controllers/AuthController.php` и замените всё содержимое на:
```php
<?php

namespace App\Http\Controllers;

use App\Models\User;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class AuthController extends Controller
{
    public function showRegister()
    {
        return view('auth.register');
    }

    public function register(Request $request)
    {
        $data = $request->validate([
            'login' => ['required', 'string', 'min:3', 'max:50', 'unique:users,login'],
            'password' => ['required', 'string', 'min:6', 'confirmed'],
        ], [
            'login.required' => 'Введите логин.',
            'login.min' => 'Логин должен быть не короче 3 символов.',
            'login.unique' => 'Такой логин уже занят.',
            'password.required' => 'Введите пароль.',
            'password.min' => 'Пароль должен быть не короче 6 символов.',
            'password.confirmed' => 'Пароли не совпадают.',
        ]);

        $user = User::create([
            'login' => $data['login'],
            'name' => $data['login'],
            'password' => $data['password'],
        ]);

        Auth::login($user);
        $request->session()->regenerate();

        return redirect()->route('home');
    }

    public function showLogin()
    {
        return view('auth.login');
    }

    public function login(Request $request)
    {
        $credentials = $request->validate([
            'login' => ['required', 'string'],
            'password' => ['required', 'string'],
        ], [
            'login.required' => 'Введите логин.',
            'password.required' => 'Введите пароль.',
        ]);

        if (! Auth::attempt($credentials)) {
            return back()
                ->withErrors(['login' => 'Неверный логин или пароль.'])
                ->onlyInput('login');
        }

        $request->session()->regenerate();

        return redirect()->intended(route('home'));
    }

    public function logout(Request $request)
    {
        Auth::logout();
        $request->session()->invalidate();
        $request->session()->regenerateToken();

        return redirect()->route('home');
    }
}
```

Пароль хешируется сам: в модели `User` уже есть `'password' => 'hashed'`.
